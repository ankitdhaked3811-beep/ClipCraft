## 2025-05-20 - Memoizing yt_dlp Metadata Extraction & Cleaning Temporary Directories
**Learning:** `yt_dlp.extract_info` performs blocking network requests to fetch web pages, player JS, and format manifests, taking 1-3+ seconds per call. Caching metadata queries with `@lru_cache` eliminates redundant network I/O for repeated video URLs in video processing endpoints, dropping response latency from ~1.5s to <0.1ms. Furthermore, `tempfile.mkdtemp()` directories leaked on disk when only individual files were deleted in background threads; removing the parent temporary directory with `shutil.rmtree` prevents disk space and inode leaks.
**Action:** Always memoize/cache external metadata extraction results in endpoints like `/info`, and ensure temporary directory trees are recursively cleaned up when temporary output files expire.
